# Changelog

Notable changes, newest first, in the [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) format. Versions use
Jellyfin's four-part numbers. Each `## [x.y.z.w]` section becomes that version's release notes and its changelog in
the plugin catalog.

## [Unreleased]

### Changed

- New plugin logo with the plugin's name. It fills the wide plugin tile instead of being zoomed and cropped.

## [1.0.2.0] – 2026-11-01

First public release.

### Added

- **Untrack show** in the ⋮ menu of episodes, seasons and shows, in the web interface and the Jellyfin phone apps. It
  marks the whole show unplayed, which removes it from Continue Watching and Next Up.
- The same option in the multi-select menu (long-press a card, then ⋮), which is how phones reach it.
